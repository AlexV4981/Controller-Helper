A LITTLE GUIDANCE

One pad. Your way to play.

Match labels keeps the letters on an Xbox pad aligned with the game: A → A, B → B. Nintendo pads keep their printed layout. PlayStation symbols are shown as printed; the assignment list shows which game action each symbol performs.

Match positions uses Nintendo’s physical layout: the right face button is A, the bottom is B. Change any assignment by clicking it and pressing a button.

Two players: select each connected controller and assign its player number. DS and 3DS games use one controller per emulator instance.

Wii: choose the game’s controller style. Galaxy uses the right stick to point; hold RB/R1/R to tilt instead. The sideways preset fits New Super Mario Bros. Wii. Motion-heavy sections still need testing in the game.

Keyboard & mouse: DS/NES keyboard input is retained. Dolphin keeps keyboard/mouse alternatives. In Cemu, select your saved KeyboardMouse profile for full keyboard play; M and Tab remain available with the Xbox GamePad profile.

Changes: close your emulators before applying. Saved mappings take effect the next time they start. Backups are kept locally, and Undo restores the last setup if an emulator hasn’t edited those files since.

This helper maps controls; it doesn’t supply games, Bluetooth hardware, motion sensors, or graphics drivers.
